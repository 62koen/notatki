## Grupowanie z liczeniem wystąpień
```sql
SELECT Kraj_produkcji, COUNT(*) AS "liczba_filmów" FROM filmy GROUP BY Kraj_produkcji;
```
## Obniżenie poprzedniej wartości
```sql
UPDATE filmy SET Cena_w_zl=Cena_w_zl-2 WHERE Gatunek="wojenny";
```
## Dwa losowe wiersze
```sql
SELECT * FROM `filmy` ORDER BY rand() LIMIT 2; 
```
