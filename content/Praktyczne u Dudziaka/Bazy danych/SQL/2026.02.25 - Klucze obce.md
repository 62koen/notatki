*Załączniki są na dole strony - **vod.sql***
1. Usuwamy tabele *klienci* i *wypozyczenia*
2. Tworzymy ręcznie tabelę *wypozyczenia*:
	```sql
	CREATE TABLE wypozyczenia ( 
	ID_wypozyczenia INT PRIMARY KEY AUTO_INCREMENT, 
	ID_filmu VARCHAR(6), 
	PESEL_klienta VARCHAR(11), 
	Data_wypozyczenia DATE );
	```
3. Dodajemy klucz obcy do *wypozyczenia*
	```sql
	ALTER TABLE wypozyczenia ADD FOREIGN KEY(ID_filmu) REFERENCES filmy(ID_filmu);
	```
