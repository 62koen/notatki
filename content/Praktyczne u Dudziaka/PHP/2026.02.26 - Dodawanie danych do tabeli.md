## **Zad.** Stworzyć pliki index.html oraz dodanie.php pozwalające dopisać nowy wiersz do tabeli **kolory** bazy danych **samochody** (kodowanie utf8_polish_ci).
*Załączniki są na dole strony - **samochody.sql***

*index.html*
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <form action="dodanie.php" method="POST">
        <input type="text" name="nazwa" placeholder="nazwa">
        <input type="text" name="doplata" placeholder="doplata">
        <input type="submit" value="Wyślij">
    </form>
</body>
</html>
```
*dodanie.php*
```php
<?php
$nazwa=$_POST['nazwa'];
$doplata=$_POST['doplata'];
$connect=mysqli_connect('localhost','root','','samochody');
// trzeba dodać apostrofy do wartości tekstowych
$sql="INSERT INTO kolory VALUES (NULL, '$nazwa', $doplata);";
$query=mysqli_query($connect,$sql);
echo $sql;
mysqli_close($connect);
?>
```
